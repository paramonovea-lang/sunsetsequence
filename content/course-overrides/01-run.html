Start the software

  1. Nothing to install. Every Strudel example on this site has a Run button. Press it to hear the code, and press Stop to stop.
  2. Click into a code block and press Ctrl+Enter to play it, or Ctrl+. to stop. On a Mac, use Cmd.
  3. Open in Strudel ↗ opens the same code in the full editor at strudel.cc. Use it to change the code, to see the visuals, and to export a WAV file.

No sound?

  1. Check the volume, the output device, and that the browser tab isn't muted.
  2. The first Run downloads Strudel and its sounds, so it can take a few seconds. A drum machine or instrument you use for the first time loads when it first plays.
  3. If a code block shows a message under it, read what the error messages mean.
