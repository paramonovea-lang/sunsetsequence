1.1What Strudel is

Strudel is a music program that runs in a web page. You write short lines of code, press Ctrl+Enter, and hear them straight away. The music is made of patterns that repeat every cycle (here, one bar). A pattern lives inside quotes: s("bd*4") means "play the sound bd (a kick drum) four times per cycle".

  • Nothing to install. It runs in the browser, and every example in this course plays with one click.
  • Sounds are built in: drum machines (TR-909, TR-808…), 128 General MIDI instruments, synths and sample sets (see the Sound bank).
  • You see what plays. Each part of the code lights up while it sounds.
  • You change the music while it plays. Edit a number, press Ctrl+Enter, and the change lands on the next cycle without stopping.
  • Short, readable errors. When something is wrong, the Error messages part says what it means.

Strudel is the JavaScript version of TidalCycles, an older live-coding language. This course uses Strudel only. Most patterns you write here look almost the same in Tidal, if you ever want to try it.

1.2Start the software

  1. Double-click E:\Tindal\start-all.bat. It starts everything in the background and opens localhost:4321 in your browser.
  2. On a code block, click Play in local Strudel. The code opens in the editor. You can also copy and paste it.
  3. Click into the editor and press Ctrl+Enter to play or update. Press Ctrl+. to stop.

When something stops working

Double-clickWhat it does
status.batShows what is running
start-all.batStarts everything that isn't running yet. It never starts anything twice.
restart-all.batStops everything and starts it fresh. Try this first when there's no sound.
restart-strudel.batRestarts only Strudel. Reload the browser page (F5) afterwards.
stop-all.batStops everything

Everything runs hidden in the background, and its output is saved in E:\Tindal\logs. The local Strudel links only work while Strudel is running. The strudel.cc button opens the same code on the public site instead.

Keeping Strudel up to date

Strudel is installed from its source code in E:\Tindal\strudel, so updating means downloading the newest code and its packages. In a terminal:

E:\Tindal\stop-all.bat                     # stop everything first
cd E:\Tindal\strudel
git log -1 --format="%cd %s" --date=short  # the date of your current version
git pull                                   # download the newest code
pnpm install                               # update the packages it needs
E:\Tindal\start-all.bat                    # start again, then reload the browser page

On 10 October 2026 your copy was the latest version (the official repository's newest commit, from 4 October 2026). Updates sometimes rename or change commands, so if an example from this course stops working after an update, check the error messages.

1.3The track: Night Bus

This is the track you build in parts 2 to 5. Play it to hear where you're going. A cycle is one bar of 4/4 here. The full form is 16 cycles, about 31 seconds, and then it loops. Layers enter every four bars, so the track builds up the way a DJ intro does.

// Night Bus · A minor · 124 BPM · 16 cycles
setcpm(124/4)

// drums
$: s("bd*4").bank("RolandTR909")
$: s("~ cp ~ cp").bank("RolandTR909")
  .mask("<0!2 1!14>")
$: s("[~ oh]*4").bank("RolandTR909").gain(.4)
  .mask("<0!2 1!14>")
$: s("hh*16").bank("RolandTR909")
  .gain("[.25 .5]*8")
  .sometimesBy(.2, x => x.ply(2))
  .mask("<0!2 1!14>")

// bass
$: note("<a1 f1 c2 g1>")
  .struct("x ~ x x ~ x x ~")
  .s("sawtooth")
  .lpf(sine.range(300, 1800).slow(8))
  .decay(.15).sustain(0)
  .mask("<0!4 1!12>")

// chords
$: chord("<Am7 F^7 C^7 G7>")
  .struct("[~ x]*2")
  .voicing()
  .s("gm_epiano1")
  .room(.5).gain(.6)
  .mask("<0!8 1!8>")

// melody
$: n("0 [~ 2] 4 [3 2]".add("<0 -2 2 -1>"))
  .scale("A4:minor")
  .s("triangle")
  .jux(rev)
  .delay(.4).gain(.5)
  .mask("<0!12 1!4>")

Where you build each layer

Each lesson adds one layer to the same code, so by the end of part 5 you have written every line above yourself.

CommandWhat it doesLesson
setcpm(124/4)
$: s("bd*4")		Sets the tempo to 124 BPM (124 beats ÷ 4 beats per bar = 31 cycles per minute) and plays a kick drum on every beat.2.1 The pulse
.bank("RolandTR909")
s("~ cp ~ cp"), s("[~ oh]*4")		Uses the sounds of the TR-909 drum machine, adds a clap on beats 2 and 4, and an open hi-hat between the beats.2.3 The drum kit
s("hh*16")
.gain("[.25 .5]*8")
.sometimesBy(.2, x => x.ply(2))		Sixteen closed hi-hats per bar, alternating quiet (.25) and louder (.5). About 1 in 5 of them (.2) plays twice in its own time.2.5 Hi-hats that breathe
note("<a1 f1 c2 g1>")
.struct("x ~ x x ~ x x ~")		The bassline: one root note per bar (A, F, C, G), played in a syncopated rhythm (x = play, ~ = rest).3.2 Bassline
chord("<Am7 F^7 C^7 G7>")
.voicing()		One chord per bar on an electric piano. F^7 is Strudel's name for Fmaj7. .voicing() picks the notes of each chord.3.3 Chords
n("0 [~ 2] 4 [3 2]")
.scale("A4:minor")		The melody, written as steps of the A minor scale (0 = A, 2 = C, 4 = E). .add("<0 -2 2 -1>") shifts it each bar to follow the chords.3.5 Melody
.lpf(sine.range(300, 1800).slow(8))
.jux(rev)		The bass filter opens and closes slowly (between 300 and 1800 Hz, over 8 bars), and the melody plays backwards in the right speaker.4.1 Movement
.mask("<0!4 1!12>")Switches a layer off for 4 bars, then on for 12. Each layer has its own mask, which makes the arrangement above.5.1 Arrangement
