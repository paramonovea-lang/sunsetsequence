# 05 · Content model

Content is files in the repo, validated at build with Astro content collections (Zod). Audio and stems are **not** in git (see `09-deployment-vps.md`).

```
src/content/
  tracks/
    sq-001.md            # frontmatter + liner notes (markdown body)
    code/sq-001.strudel  # the full track code, shown and opened in Strudel
  lessons/
    01-start-here.html   # generated by scripts/migrate-course.mjs (see below)
    ...
    meta.json
media/ (outside git, synced to the VPS)
  audio/sq-001.wav       # WAV rendered in Strudel (current releases); a 320 kbps .mp3 works too (the field is named audio.mp3)
  peaks/sq-001.json      # waveform peaks (audiowaveform, or scripts/wav-peaks.mjs for a WAV)
  stems/sq-001-stems.zip # optional
```

## Track schema

```ts
// src/content.config.ts (excerpt)
const step16 = z.string().regex(/^[x.]{16}$/);
const tracks = defineCollection({
  loader: glob({ pattern: '*.md', base: './src/content/tracks' }),
  schema: z.object({
    id: z.string().regex(/^SQ-\d{3}$/),          // catalogue number, release order
    title: z.string(),
    slug: z.string().regex(/^[a-z0-9-]+$/),        // URL: /tracks/[slug]/
    status: z.enum(['released', 'upcoming']).default('released'),
    released: z.coerce.date(),
    style: z.string(),                             // e.g. "deep house"
    bpm: z.number().int().min(40).max(220),
    key: z.string(),                               // "A minor"
    formCycles: z.number().int().optional(),       // length in cycles (bars)
    length: z.string().regex(/^\d+:\d{2}$/),       // "5:12"
    chords: z.array(z.string()).default([]),       // ["Am7","Fmaj7",...]
    engine: z.enum(['strudel', 'tidal', 'both']).default('strudel'),
    drums: z.string().optional(),                  // "RolandTR909"
    sequence: z.object({                           // one representative cycle
      kick: step16, clap: step16.optional(), hats: step16.optional(),
      openHat: step16.optional(), bass: step16.optional(), chords: step16.optional(),
    }),
    code: z.string(),                              // "code/sq-001.strudel"
    audio: z.object({ mp3: z.string(), peaks: z.string(), stems: z.string().optional() }),
    credits: z.object({ producer: z.string(), mastering: z.string().optional() }),
    licenses: z.object({ audio: z.string(), code: z.string() }),
    links: z.object({ bandcamp: httpsUrl.optional(), spotify: httpsUrl.optional(), soundcloud: httpsUrl.optional() }).default({}), // httpsUrl = https:// links only
    lessons: z.array(z.string()).default([]),      // related lesson slugs
    coverPalette: z.enum(['dusk', 'lagoon', 'reef', 'ember', 'mist', 'noon']).optional(),
    hasLinerNotes: z.boolean().default(true),
    placeholder: z.boolean().default(false),       // dev stand-in: numbers drive the cover, pages show [bpm], [key] …
  }),
});
```

Files are named by catalogue number (`sq-001.md`); the URL uses `slug`. The catalogue number never changes; if a slug changes, add a redirect (Caddy) from the old URL.

Ordering: catalog shows newest first by `released`. `upcoming` tracks appear only as "coming soon" cards at the start of the catalog (home and `/tracks/`, both views): cover, title, style, BPM, key; no link, no play button, no track page, player entry, feed item or social image until `status: released`.

## Lessons and guided sequences

Lessons are **generated HTML**, not a content collection (docs/08): `scripts/migrate-course.mjs` writes
`src/content/lessons/<slug>.html` (the page's sections, in the course's own codebox format) and
`src/content/lessons/meta.json` (`{ "<slug>": { lede, onpage: [{ id, label }] } }`). Part titles and
one-line descriptions live in `src/lib/course.ts` (`PARTS`). Never edit the generated files; change the
course and re-run the script.

Guided sequences (`src/lib/guided.ts`):

```ts
type Guide = {
  id: string;          // URL: /course/<lesson>/<id>/
  lesson: string;      // lesson slug
  anchor: string;      // id in the lesson where the "Build … step by step" card goes
  title: string;
  stepWord: string;    // "Layer" | "Step"
  nextLabel: string;
  steps: { title: string; html: string; listen?: string; code: string /* "+ " marks new lines */; grid?: { label; color; pattern }[] }[];
};
```

Hand-written ones are JSON in `content/guided/` (`drum-kit.json`; `grid` there names rows from its `rows` map);
part 11's "How it was made" sequences are extracted from the lesson HTML at build.
